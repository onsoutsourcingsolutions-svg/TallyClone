# Excel Templates — O.N.S. OUTSOURCING SOLUTIONS

These 4 files are the fixed "always the same" format for bulk data.
They can also be downloaded any time from the app: Company → Import / Export.

ORDER OF WORK (do once, in this order):
  1) template-1-ledgers.xlsx    — parties, banks, expense/income heads. Required: name + group.
  2) template-2-stock-items.xlsx — all stock items/services: name, unit, HSN, GST rate. You can add lakhs of rows.
  3) template-3-opening-stock.xlsx — item_name (must already exist), qty, rate. Upload with date + balancing account.
  4) template-4-vouchers.xlsx    — past receipts/payments/journal entries, one Dr+Cr row each.

RULES
  - Keep the header row as it is. Delete the EXAMPLE row before uploading.
  - Duplicate names are skipped. To update existing instead, switch the import option to Update.
  - Every file works as .xlsx, .xls or .csv with the same column order.
  - You can download "My current data" export from the app at any time for backup.
